怎麼切換成正式首頁

  1. 把選定的那一版改名成 index.html，這一頁可以刪掉，或改名成 directions.html 留著對照。
  2. 替換所有示範文案：姓名、經歷、專案名稱、成果數據、Email 與 GitHub 連結（搜尋「示範」可快速定位）。
  3. 把每張 .cover 裡的抽象 .cover-art 換成真實專案截圖，保留這兩層結構，hover 放大與濾鏡切換都會繼續運作。
  4. 四版都只依賴 assets/css/base.css、assets/css/fonts.css 與 assets/js/site.js，共用檔案請一起保留。
